# 히든보스 스프라이트 제작 프롬프트

히든보스 3명(선조의 잔상 · 왕실특무마기법사 · 오리온의 성전사)의 본체 자세와 패턴 이펙트를 만들기 위한 프롬프트다.
패턴의 동작·타이밍은 지금 게임 데이터(`src/data/bosses.json`) 기준이다. 세계관 설정은 기획서에 있는 것만 썼다.

## 공통 규칙 (모든 프롬프트에 붙인다)

```
[공통 스타일]
- 16비트풍 고해상도 도트 그래픽, 다크 판타지, 탑다운 액션 게임용 스프라이트
- 배경 완전 투명(PNG 알파), 그림자·바닥·글자·테두리 상자 없음
- 캐릭터는 오른쪽을 본다(왼쪽은 게임에서 뒤집는다)
- 한 시트 안의 모든 프레임은 같은 크기·같은 배율·같은 발 위치(발끝 기준선 고정)로 그린다
- 칸마다 그림 둘레에 여백 10% 이상: 칼끝·망토·빛·파편이 칸 가장자리에 닿거나 잘리면 안 된다
- 칸 밖으로 옆 칸 그림이 넘어오거나, 칸 안에 떠 있는 선·점·글자가 있으면 안 된다
- 가로 한 줄 시트, 칸 크기 동일, 칸 사이 간격 0
- 외곽선은 1px 어두운 선, 광원은 왼쪽 위
```

본체 시트는 "자세마다 한 시트"로 받는다. 자세 크기가 서로 다르면 게임에서 갑자기 커지거나 작아져 보이므로, 대기 자세와 같은 키로 그려 달라고 반드시 적는다.
이펙트는 프레임마다 단계가 보이게 한다: 1 준비·응축 → 2 타격·방출 → 3 확장·분해 → 4 소멸·잔류.

## 1. 선조의 잔상 (ancestorEcho)

야만용사 시초인 인간 각성자의 전투 기록을 재현한 잔상. 지금 그림: 금발 장발에 근육질 상반신, 해골 장식 허리띠, 붉은 천 허리치마, 대검. 대기 1장·이동 2장뿐이라 공격 자세가 없다.
2페이즈(체력 50%): 이동 속도 ×1.3, 몸집 ×1.15, 주황 오라(#ff5a2a).

### 1-0. 본체 자세

```
[선조의 잔상 본체 — 자세 시트]
위 공통 스타일. 금발 장발의 근육질 야만 전사, 상반신 맨몸에 흉터, 해골 장식 허리띠, 붉은 천 허리치마, 털 부츠, 한 손 대검.
반투명하게 일렁이는 '전투 기록의 잔상' 느낌: 몸 가장자리에 옅은 주황·붉은 잔상 번짐.
다음 자세를 각각 따로, 대기 자세와 같은 키·같은 배율로:
1) 대기 4프레임(숨쉬기, 반복)
2) 이동 6프레임(성큼 걷기, 반복)
3) 포효 4프레임: 가슴을 펴고 고개를 젖혀 외침, 1회
4) 돌진 준비 3프레임: 몸을 낮추고 대검을 뒤로 끌어당김, 1회
5) 돌진 4프레임: 대검을 앞세워 회전하며 돌진(빠른 움직임 번짐), 반복
6) 내려찍기 4프레임: 대검을 머리 위로 → 땅에 내리꽂음, 1회
7) 2페이즈 대기 4프레임: 같은 인물, 주황 오라가 타오르고 눈이 빛남
```

### 1-1. 전장의 함성 (warCry)
0.8초 준비 후 포효, 6초(2페이즈 8초) 동안 자기 강화(피해 ×1.3, 이동 ×1.4).

```
[이펙트 — 전장의 함성]
위 공통 스타일. 전사가 외칠 때 몸 중심에서 퍼지는 주황·붉은 음파 고리와 거친 붓터치 같은 충격선, 흩날리는 먼지.
4프레임 1회, 추천 14fps. 정사각형 칸, 고리는 캐릭터 키의 2.5배까지 퍼진다.
추가로 '강화 오라' 4프레임 반복: 발밑에서 위로 일렁이는 주황 불꽃 테두리(캐릭터 뒤에 겹칠 용도, 가운데는 비움).
```

### 1-2. 소용돌이 돌진 (whirlDash)
0.4초 예고 → 길이 200 직선 돌진 ×3(2페이즈 4), 매번 다시 조준.

```
[이펙트 — 소용돌이 돌진]
위 공통 스타일.
1) 돌진 궤적: 대검이 회전하며 남긴 붉은 칼바람 소용돌이, 가로로 긴 그림(가로:세로 4:1), 4프레임 1회 16fps
2) 돌진 시작 발 구르기: 흙먼지와 붉은 충격 고리, 4프레임 1회 16fps
```

### 1-3. 출혈 장판 (bleedField)
플레이어 주변 3곳(2페이즈 5곳)에 0.5초 예고 원 → 4초 동안 지속 피해 장판(반경 22).

```
[이펙트 — 출혈 장판]
위 공통 스타일. 위에서 내려다본 바닥 장판.
1) 예고: 바닥에 번지는 붉은 핏자국 원 윤곽, 4프레임(점점 진해짐) 1회
2) 장판: 피웅덩이와 그 위로 솟는 붉은 칼날 같은 가시, 가장자리에서 핏방울이 튐, 4프레임 반복 10fps
원형, 정사각형 칸 중앙.
```

### 1-4. 지면 파괴 (groundBreak)
0.8초 예고 → 플레이어 자리 내려찍기(반경 28) → 지나갈 수 없는 잔해가 남음(반경 14, 최대 4개).

```
[이펙트 — 지면 파괴]
위 공통 스타일.
1) 내려찍기 충격: 땅이 거미줄처럼 갈라지며 흙·돌 파편이 튀고 주황 섬광, 4프레임 1회 14fps, 정사각형
2) 잔해(장애물): 바닥에서 솟은 깨진 바위 덩어리 1개, 1장(정지), 위에서 약간 비스듬히 본 모습, 판정 반경보다 조금 크게
```

### 1-5. 연속 내려찍기 (earthShatter, 2페이즈)
플레이어 쪽으로 이어지는 강타 4번(간격 36, 0.18초 간격, 반경 22).

```
[이펙트 — 연속 내려찍기]
위 공통 스타일. 한 번의 강타 자리에서 솟는 주황 불꽃 섞인 바위 파열, 4프레임 1회 16fps, 정사각형.
여러 개가 줄지어 터지므로 하나만 그린다.
```

## 2. 왕실특무마기법사 (royalMage)

왕실을 호위하는 고위 마기법사. 지금 그림은 임시(다른 캐릭터를 보라색으로 칠한 것)라 본체부터 새로 필요하다.
2페이즈(체력 50%) '마기화': 이동 속도 ×1.5, 보라 오라(#b05aff), 강력한 근접 공격이 추가된다.

### 2-0. 본체 자세

```
[왕실특무마기법사 본체 — 자세 시트]
위 공통 스타일. 왕실을 호위하는 고위 마기법사. 단정한 왕실 예복 로브(짙은 남색·보라), 금색 장식 견장과 왕실 문장, 긴 지팡이(마법 지팡이).
기품 있고 절제된 자세, 손끝과 지팡이 끝에 보라색 마기 빛.
다음 자세를 각각 따로, 대기 자세와 같은 키·같은 배율로:
1) 대기 4프레임(로브 자락이 살짝 흔들림, 반복)
2) 이동 6프레임(미끄러지듯 걷기, 반복)
3) 시전 4프레임: 지팡이를 들어 올리고 보라 마법진이 손에 모임, 1회
4) 레이저 발사 4프레임: 지팡이를 앞으로 겨눔, 1회
5) 순간이동 사라짐 4프레임 / 나타남 4프레임: 보라 입자로 흩어짐 ↔ 모임, 1회씩
6) 2페이즈 '마기화' 대기 4프레임: 같은 인물, 몸에 보라 마기 균열이 번지고 눈과 손이 강하게 빛남
7) 2페이즈 강타 6프레임: 마기로 감싼 손(또는 지팡이)으로 앞을 크게 휘두름 — 연속 3타 중 한 동작, 1회
```

### 2-1. 순간이동 탄막 (blinkBarrage)
0.3초 사라짐 → 120 이상 떨어진 곳에 나타남 → 원형 탄막 2겹(2페이즈 3겹), 겹마다 16발.

```
[이펙트 — 순간이동 탄막]
위 공통 스타일.
1) 사라짐·나타남 섬광: 보라 입자가 소용돌이치며 모였다 흩어지는 원형 이펙트, 4프레임 1회 14fps
2) 탄막 발사 고리: 마법사 둘레에 펼쳐지는 보라 룬 원(바깥쪽으로 퍼짐), 4프레임 1회 14fps
3) 탄환: 작은 보라 마기 구슬(빛나는 핵 + 짧은 꼬리), 오른쪽을 향함, 4프레임 반복 12fps, 아주 작게(16px 기준)
```

### 2-2. 강력한 레이저 (greatLaser)
1초 예고선 → 굵은 직선 레이저 0.6초(길이 420, 폭 14). 대형 레이저라 반사·베기 불가.

```
[이펙트 — 강력한 레이저]
위 공통 스타일.
1) 예고선: 가늘게 맥박치는 보라 조준선, 가로로 긴 타일(왼쪽 끝은 지팡이 끝), 4프레임 반복
2) 레이저 본체: 흰 심에 보라·자주 테두리, 가장자리가 지글거리는 굵은 광선. 가로로 이어 붙여 늘일 수 있게(좌우 끝이 이어지는 타일), 3프레임 반복 18fps
3) 발사구 섬광: 지팡이 끝에서 터지는 보라 별빛, 4프레임 1회
```

### 2-3. 분신 (clones)
분신 2기 소환(체력 15%, 8초 유지, 1.5초마다 탄 한 발).

```
[분신 — 본체 변형]
위 공통 스타일. 왕실특무마기법사 본체와 같은 그림을 반투명 보라 실루엣으로(속이 비치는 유령 같은 분신), 대기 4프레임 반복.
추가: 분신이 생길 때·사라질 때 보라 거울 조각이 깨지는 이펙트 4프레임 1회.
```

### 2-4. 마기 강타 (magiStrike, 2페이즈)
0.4초 준비 → 플레이어에게 돌진 → 0.25초 간격 부채꼴 연타 3번(반경 42, 120°).

```
[이펙트 — 마기 강타]
위 공통 스타일.
1) 돌진 잔상: 보라 마기 꼬리, 가로로 긴 그림, 4프레임 1회
2) 부채꼴 강타: 120° 부채꼴로 쓸고 지나가는 보라 마기 참격(중심은 시전자, 오른쪽을 향함), 4프레임 1회 16fps. 연타 3번에 같은 그림을 방향만 바꿔 쓴다
```

## 3. 오리온의 성전사 (orionCrusader)

마기법사 오리온 가문의 강력한 성기사. 지금 그림: 금빛 갑옷 기사, 붉은 망토, 큰 방패. 대기 3장·이동 6장, 공격 자세가 없다.
2페이즈(체력 50%) '성광': 이동 속도 ×1.2, 몸집 ×1.1, 연노랑 오라(#fff2a0).

### 3-0. 본체 자세

```
[오리온의 성전사 본체 — 자세 시트]
위 공통 스타일. 마기법사 오리온 가문의 성기사. 금빛 판금 갑옷, 깃 장식 투구, 붉은 망토, 가문 문양이 새겨진 큰 방패, 한 손 메이스.
다음 자세를 각각 따로, 대기 자세와 같은 키·같은 배율로:
1) 대기 4프레임(망토 흔들림, 반복)
2) 이동 6프레임(묵직하게 걷기, 반복)
3) 메이스 강타 6프레임: 메이스를 들어 올렸다 앞으로 크게 내려침, 1회
4) 방패 투척 4프레임: 방패를 옆으로 회전시켜 던짐, 1회 (던진 뒤 손에 방패 없음 1프레임 포함)
5) 기도·성검 소환 4프레임: 메이스를 하늘로 들어 올리고 위에서 빛이 내려옴, 1회
6) 2페이즈 '성광' 대기 4프레임: 같은 인물, 갑옷 틈과 눈에서 연노랑 빛이 새어 나오고 등 뒤로 빛살
```

### 3-1. 성검 낙하 (holySwords)
플레이어 둘레에 0.15초 간격으로 0.8초 예고 원 6개(2페이즈 10개) → 성검이 꽂힘(반경 14).

```
[이펙트 — 성검 낙하]
위 공통 스타일.
1) 성검: 하늘에서 수직으로 떨어지는 빛나는 금빛 장검(칼끝 아래), 세로로 긴 칸, 1장 또는 빛 꼬리 포함 3프레임
2) 꽂힘 충격: 칼이 박힌 자리에서 금빛 십자 섬광과 원형 빛 고리, 흙 파편, 4프레임 1회 16fps, 정사각형
3) 예고 원: 바닥의 금빛 성문(문장) 원, 4프레임 반복(점점 밝아짐)
```

### 3-2. 메이스 강타 (maceSmash)
가까울 때 0.6초 준비 → 앞쪽 120° 부채꼴(반경 40).

```
[이펙트 — 메이스 강타]
위 공통 스타일. 메이스가 땅을 내려친 앞쪽으로 퍼지는 금빛·주황 충격파 부채꼴(120°, 시전자 기준 오른쪽), 바위 파편과 먼지, 4프레임 1회 14fps.
```

### 3-3. 방패 투척 (shieldThrow)
방패가 방 벽에 3번(2페이즈 5번) 튕기며 날아다님(반경 7, 최대 8초).

```
[이펙트 — 방패 투척]
위 공통 스타일.
1) 날아가는 방패: 위에서 본 회전하는 가문 문양 방패(금빛 테두리, 붉은 바탕), 4프레임 반복 16fps(한 바퀴 회전), 작게
2) 벽에 튕길 때 불꽃: 금빛 불티와 짧은 충격선, 3프레임 1회
```

### 3-4. 성검 십자 낙하 (judgment, 2페이즈)
플레이어를 지나는 가로·세로 줄을 따라 간격 32로 성검이 연달아 떨어짐(0.04초 간격, 1초 예고, 반경 13).

```
[이펙트 — 성검 십자 낙하]
위 공통 스타일.
1) 심판의 십자: 바닥에 그려지는 거대한 금빛 십자 문양(가로·세로 줄이 빛으로 그어짐), 4프레임 1회 12fps, 정사각형 큰 칸
2) 성검 하나의 낙하·충격은 3-1과 같은 그림을 쓴다
```
