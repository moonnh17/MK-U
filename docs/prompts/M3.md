M2가 끝났어. 이어서 **M3**를 진행하자.

먼저 `CLAUDE.md`, `docs/PROGRESS.md`, `docs/DECISIONS.md`를 읽어서 현재 상태를 파악하고, `docs/MKU_REBOOT.md`에서 아래 섹션을 읽어줘. 이 프롬프트의 요약보다 **문서가 우선**이다.

- 런 구조, 스테이지·방 설계 (보스방)
- 챕터별 적·보스 로스터 (챕터1, 보스 패턴, 엘리트)
- 캐릭터·직업·전직 시스템 (전직 판정 규칙, 시스템 구조, 전직 후 스킬 변환)
- 스킬 레벨·각성·궁극기, 마기학자 상세 (궁극기 벼락·특이점 실험과 각성)
- 태그 시스템 (공간격의 보스 규칙)
- 연출 (스킬 각성·궁극기 각성·전직)
- 인벤토리 (전직 후 스킬 변환 기록)

그다음 **코드를 쓰기 전에 M3 구현 계획부터 보여줘.** 내가 승인하기 전에는 파일을 만들지 마. 기획서에 없는 규칙 중 정해야 할 게 있으면 질문 목록으로 한꺼번에 물어봐.

## 목표

1-1 ~ 1-5를 엘리트가 섞인 챕터1 적과 싸우며 진행하고, 1-2 융합악귀·1-5 전기환띠를 패턴이 있는 보스로 잡는다. 1-5 보스를 잡으면 챕터1에서 고른 계열로 자동 전직하고, 전직 연출과 스킬 변환을 본 뒤 학파 궁극기를 쓸 수 있게 한다. 스킬 각성·궁극기 각성도 컷인 → 설명창으로 보여준다.

M3도 **세 단계로 나눠서** 진행한다. 각 단계가 끝나면 커밋하고 내 확인을 받은 뒤 다음으로 넘어간다.

## M3-A — 적 공격과 엘리트

1. **적 공격 기반**: 적 투사체·근접 공격 판정을 정식으로 만든다. M2-B에서 만든 적 탄(피해, `refractable`, `cuttable`)을 그대로 쓰고, 근접·장판·보스 대형 레이저는 무효화·탄 베기 대상에서 뺀다. 공격 전 예고(예고선·예고 원)를 데이터로 둔다.
2. **챕터1 일반 적 3종**: 문서의 역할(토마끼 물량, 개들개 고속 추격, 악귀 근접 중장)에 맞게 행동을 다듬는다. 구체 패턴은 계획에서 제안하고 내 확인을 받는다.
3. **엘리트 3종**(거대·신속·폭발): 문서의 효과와 표시(외곽선·잔상·깜빡임 + 아이콘), 공통 크기 1.3배·체력 ×3·처치 보상 추가. 한 개체에 하나만, 보스 제외.
4. **엘리트 등장 수**: 전투 칸 웨이브마다 X-1은 1마리, X-3 이후 1~2마리(문서 제안값). 시드 RNG로 재현 가능해야 한다.
5. **확인 못 했던 것**: 칼 탄 베기와 벡터굴절역장을 실제 적 탄으로 확인한다.

## M3-B — 챕터1 보스

1. **보스방**: 입장 전 경고 연출, 보스 등장 후 문 잠금, 처치 시 기존 흐름(보스 카드 → 포털)으로 이어진다.
2. **융합악귀 (1-2)**: 악귀 할퀴기, 원혼 돌진(마기 영역 남김), 악귀 분출, 원혼 폭발. 체력 50% 이하에서 폭주(이동·돌진 가속, 분출 증가).
3. **전기환띠 (1-5)**: 낙뢰 추적, 전격 파문, 회전 번개, 전격 감옥. 체력 50% 이하에서 거대화·푸른 오라, 청뢰 돌진 + 뇌전 봉쇄·수축 전류 추가.
4. 패턴 순서·수치·예고 시간은 데이터에 임시값으로 두고 `DECISIONS.md`에 기록한다. 패턴 상태 전이(선택·쿨타임·강화 단계 진입)는 순수 함수로 만들고 테스트한다.
5. 보스는 엘리트가 붙지 않고, 공간격은 즉사 없이 ×2.4 피해(이미 구현된 규칙 사용).

## M3-C — 전직과 연출

1. **전직 판정**: 1-5 보스 처치 후, M2에서 모은 `schoolPicks`로 많은 쪽으로 자동 전직한다(동점 처리는 히든보스가 생기는 M4 이후).
2. **직업 데이터**: 문서의 Class 데이터 구조(이름, 기본 스탯 보정, 기본 무기, 스킬 풀, 기본 궁극기, 전직 분기 2개)로 마기학자를 채우고, 마기법사·전사는 `enabled: false`로 틀만 둔다.
3. **스킬 변환**: 반대 학파 스킬(패시브 포함) 제거 → 레벨 합만큼 변환 포인트 → 자기 학파 스킬 무작위 +1(Lv3 제외) → 남으면 무작위 스탯 +3 → 빈 슬롯은 보관함의 자기 학파 스킬로 자동 채움. 각성은 옮겨가지 않는다. 결과는 인벤토리 스킬 탭에 기록으로 남긴다.
4. **전직 후 카드 풀**: 자기 학파 스킬·패시브만 나온다.
5. **학파 궁극기**: 헥타르 벼락(공간격 직선 절단), 아크로 특이점 실험(끌어당긴 뒤 붕괴·증식·변질·과부하·대실패 중 하나, 공간격은 붕괴만). 게이지는 문서대로 헥타르는 설치 병기 공격, 아크로는 실험 효과로 데이터가 쌓인다.
6. **궁극기 각성**: 자기 학파 스킬(패시브 포함) 2개를 각성하면 추가 카드 없이 자동 각성. 케라우노스, 특이점 실험 : 역설(관측 → 표식 적에게 준 실제 피해 기록 → 일부·상당 부분·전부(대성공) 재현, 재현 피해는 다시 기록하지 않음).
7. **연출**: 스킬 각성·궁극기 각성·전직을 문서의 '컷인 → 설명창'으로 만든다. 게임을 멈추고, PC는 아무 키, 모바일은 화면 탭으로 넘긴다. M2의 각성 토스트는 이것으로 바꾼다. 전직 설명창은 3장(전직명·판정 결과·교체된 궁극기 / 스킬 변환 목록 / "이제부터 OO 스킬만 등장합니다").
8. **전직 이후 흐름**: 연출이 끝나면 지금처럼 '챕터1 클리어(임시)' 화면으로 간다. 챕터2는 M6이다.
9. **디버그**: 엘리트 지정 소환, 보스 소환, 보스 체력 설정(강화 단계 확인), 계열 집계 설정 후 전직 즉시 실행, 궁극기 각성 확인.

## 구현 규칙

- 수치·확률·예고 시간·패턴 순서는 **임시값으로 데이터에 두고** `DECISIONS.md`에 기록한다.
- 적·보스·패턴·궁극기 이름은 문서를 **바꾸지 않는다.** 문구는 `src/data/text/ko.json`에 둔다.
- 학파 색(헥타르 푸른색, 아크로 붉은색), 엠블럼, 실루엣은 색 도형으로 대신하고 스프라이트 키만 데이터로 둔다.
- 세계관 미공개 설정은 지어내지 않는다.
