# 성기사 스킬 이펙트 정리 (각성 이펙트 제작용)

성기사 스킬 6개와 궁극기의 지금 이펙트를 모았다. 각성 이펙트를 그릴 때 크기·프레임·쓰임새를 맞추는 기준으로 쓴다.

- `<스킬 id>.png`: 맨 위는 아이콘, 그 아래 줄은 Lv1·Lv2·Lv3 이펙트 프레임. 2배 확대, 칸 하나가 프레임 하나.
- `divineJudgment.png`: 궁극기 심판의 강림 (sword / impact / shield).
- `reference/`: 야만용사 각성 이펙트 3종. 각성 이펙트가 일반 이펙트와 얼마나 달라야 하는지 보는 참고(크기 140, 프레임 16~34장).
- 게임 원본: `public/assets/mku/skill_p*.png`, 정의는 `src/data/art.json`, 쓰는 코드는 `src/skills/paladin.ts`.

## 각성 이펙트 규격 (만들 것)

야만용사 각성과 같은 방식으로, 스킬마다 각성 그림 하나(`…A`)를 둔다.

| 스킬 | 새 그림 키 | 권장 크기·프레임 |
| --- | --- | --- |
| 성스러운 방벽 | `skill_pShield_shieldA` | 80×80, 8~12장, 반복 가능 |
| 응징의 서약 | `skill_pOath_oathA` | 140×140, 12~16장 |
| 성역 오라 | `skill_pAura_auraA` | 140×140, 8~12장, 반복 |
| 강타 | `skill_pSmite_smiteA` | 140×140, 12~16장, 오른쪽을 본다 |
| 성검 | `skill_pSwords_swordA` | 100×100, 10~14장 |
| 회생의 기도 | `skill_pPrayer_prayerA` | 80×80, 10~14장 |
| 심판의 강림 | `ult_judgment_swordA`, `ult_judgment_impactA` | 140×140, 12~16장 |

- 한 장에 프레임을 가로로 이어 붙이거나, 프레임마다 따로 그린 그림 모두 괜찮다. 배경은 투명 또는 단색 초록(지운다).
- 원본은 큰 그림(프레임 256px 이상)도 괜찮다. 빌드할 때 위 크기로 줄인다.
- 받은 원본은 `scripts/art-src/paladin-awakening/`에 넣고, 빌드 스크립트를 붙인다.

## 각성 구상안 (제안, 확정 아님)

페르세우스 신화를 모티브로 한 요구 아이템·각성 방향이다. 이름·효과·등급은 정해지면 바꾼다. 플레이버 문구는 비워 둔다.

| 스킬 | 요구 아이템 (등급) | 각성 이름 | 각성 방향 | 이펙트 그림 방향 |
| --- | --- | --- | --- | --- |
| 성스러운 방벽 | 아테나의 거울 방패 (전설) | 거울 방패 | 방패가 튕길 때마다 둘레의 적 탄환을 되받아 친다. 방패를 든 동안 앞에서 오는 탄환을 막는다 | 거울처럼 빛을 반사하는 둥근 방패, 튕길 때 빛줄기 |
| 응징의 서약 | 키비시스 (레어) | 메두사의 응시 | 반격에 맞은 적이 잠시 돌이 된다(보스는 느려짐). 돌이 된 적은 받는 피해 증가 | 반격 고리에 뱀 머리카락·회색 석화 파동 |
| 성역 오라 | 안드로메다의 사슬 (레어) | 안드로메다의 수호 | 오라 끝에 빛의 사슬이 생겨 안의 적을 끌어당기고 잠시 묶는다 | 오라 둘레를 도는 금빛 사슬 고리 |
| 강타 | 하르페 (전설) | 고르곤 참수 | 참격이 초승달 낫 모양으로 나갔다가 돌아오며 두 번 벤다. 체력이 낮은 일반 적은 즉사 | 크게 휜 낫 모양 참격 |
| 성검 | 페가수스의 깃털 (레어) | 천마 강림 | 성검이 하늘을 가로지르는 천마의 궤적을 따라 줄지어 떨어진다(개수 증가) | 날개 달린 성검, 깃털 흩날림 |
| 회생의 기도 | 다나에의 금빛 비 (레어) | 황금 빗줄기 | 기도할 때마다 둘레에 금빛 비가 내려 적에게 피해, 아군 회복량 증가 | 머리 위에서 쏟아지는 금빛 빗줄기 |
| 심판의 강림 | 알골의 눈 (유니크, 일반 상자 풀) | 미르팍의 기억 | 심판의 검이 셋으로 늘고, 착지 자리 둘레 적이 돌이 된다. 성기사가 들면 궁극기 쿨타임 감소 | 세 자루 검 + 석화 충격파 |

- 야만용사가 헤라클레스 별자리(라스알게티)로 궁극기 각성 이름을 지은 것처럼, 페르세우스자리의 으뜸별 미르팍과 '악마의 별' 알골(메두사의 머리)을 썼다.
- 탈라리아(헤르메스의 날개신)·하데스의 투구는 남는 후보다. 회피(도약처럼 성기사 전용 회피)나 다른 아이템에 쓸 수 있다.
