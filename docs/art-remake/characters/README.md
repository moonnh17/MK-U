# 캐릭터 스프라이트 리메이크 자료 (마기학자·전사)

지금 게임에 들어간 플레이어 스프라이트 6종을 모았다. 리메이크할 때 이 폴더를 그대로 넘기면 된다.

- `all_characters.png`: 6종 전체. 한 줄이 한 캐릭터, 왼쪽부터 프레임 순서. 회색 칸이 프레임 하나.
- `player_*_x4.png`: 캐릭터별 시트. 게임 시트를 4배로 키웠다(nearest).
- 게임 원본: `public/assets/mku/player_*.png`. 정의는 `src/data/art.json`에 있다.

모든 시트가 공통으로 따르는 규칙:

- 시트 높이는 52px이고 `density 2`다. 게임 화면에서는 **키 26px**로 보인다(기준 해상도 480×270).
- 프레임은 가로 한 줄로 이어 붙인다. 대기 프레임이 먼저, 이동 프레임이 그다음이다.
- 왼쪽으로 **움직일** 때 게임이 좌우로 뒤집는다(조준 방향이 아니라 이동 방향 기준). 그래서 그림은 **오른쪽(또는 정면)** 을 보게 그린다.
- 무기는 몸과 따로 그린다. 게임이 몸 가운데에서 **화면 오른쪽 5px, 위 6px**(게임 픽셀) 자리에 든 무기를 겹쳐 그린다.

## 지금 그림의 문제 (리메이크할 때 맞출 것)

1. **방향이 다르다.** 마기학자 계열은 정면, 전사와 성기사는 3/4 오른쪽, 야만용사는 완전히 옆이다.
2. **프레임 수가 다르다.** 대기 1/4/3장, 이동 2/4/6장으로 섞여 있다. 야만용사는 이동이 2장뿐이라 걸음이 끊겨 보인다.
3. **무기가 겹친다.** 전사(검), 성기사(방패·메이스)는 몸 그림에 무기가 들어 있다. 그런데 게임이 든 무기를 따로 그리니 무기가 두 개로 보인다. 마기학자 계열은 빈손이다.
4. **폭과 크기가 다르다.** 프레임 폭이 34~48px로 다르고, 머리 위치와 체격 비율이 줄마다 다르다.

## 리메이크 규격 (제안)

여섯 종 모두 똑같이 맞춘다.

- 방향: 3/4 오른쪽
- 대기 4장(4fps), 이동 6장(8fps)
- 배경은 투명, 발밑은 칸 아래 가운데, 머리 높이는 여섯 종이 같게
- 손에 무기를 들지 않는다. 방패처럼 몸에 붙은 장비만 그린다. 무기는 게임이 오른손 자리에 따로 그린다.
- 원본은 큰 그림(칸 256px 이상)으로 그린다. `scripts/build-art.cjs`가 키 26px(시트 52px)로 줄인다.
- 전직 캐릭터(헥타르·아크로 / 야만용사·성기사)는 기본 직업과 실루엣을 맞추고 색·장식으로 구별한다. 지금 헥타르는 파란 장치, 아크로는 붉은 장치를 단 것과 같은 방식이다.

## 게임에 넣는 방법

1. 원본 그림을 v174 폴더 자리(`scholars.png`, `warrior/*.png`)에 넣거나, `scripts/build-art.cjs`의 `player_` 줄이 가리키는 파일 이름을 바꾼다.
2. `npm run art:build -- "<v174 assets 경로>"`를 돌린 다음 `npm run assets`를 실행한다.
3. 프레임 수가 바뀌면 build-art가 `art.json`의 `anims`를 새로 만든다. 따라서 코드는 고칠 필요가 없다.
