# 효과음 출처

녹음 효과음은 Freesound의 CC0(퍼블릭 도메인) 소리만 썼다. 라이선스는 소리마다 자기 페이지에서 확인했다 (조건 없음, 출처 표기는 예의로 남긴다).
파일은 잘라 내고(한 번의 소리만), 끝을 짧게 줄이고, 모노 44.1 kHz OGG로 바꾸고, 봉우리 -2 dBFS로 맞췄다.
나머지(UI·연출음)는 이어샷(earshot) 내장 소리 은행에서 만들었다 (코드로 합성한 소리, 녹음 아님).
